## Блок 1, №11 — наибольший общий делитель

Задание: вычислить НОД двух натуральных чисел рекуррентным способом.

`nod(FirstNumber, SecondNumber, Result)` использует алгоритм Евклида:
НОД(A, B) = НОД(B, A mod B). Когда второй аргумент равен нулю,
ответ — первый аргумент. Вводи неотрицательные целые числа;
для пары (0, 0) решения нет.

```prolog
nod(48, 18, Result).
% Result = 6.

nod(17, 13, Result).
% Result = 1.

nod(12, 12, Result).
% Result = 12.
```

## Блок 2, №8 — свойственник

Задание: разработать рекурсивную программу «свойственник»
по материалам «Родственных отношений» из лабораторной 1.

Используются те же родители и текущие браки, что в Lab1.
Свойственник здесь — кровный родственник супруга или супруг кровного
родственника. Сами супруги этим правилом не считаются свойственниками
только на основании своего брака.
Кровные родственники самого человека исключаются из ответа.

`ancestor/2` рекурсивно проходит цепочку родителей.
`blood_relative/2` находит предков, потомков и людей с общим предком.
`in_law(InLaw, Person)` находит свойственника InLaw человека Person через брак
и кровное родство. Родословная предполагается без циклов.

```prolog
in_law('Сергей', 'Анна').
% true: Сергей — отец мужа Анны.

in_law('Анна', 'Сергей').
% true: Анна — жена сына Сергея.

setof(InLaw, in_law(InLaw, 'Сергей'), People).
% People = ['Анна', 'Марина'].

setof(Person, in_law(Person, 'Анна'), People).
% People = ['Андрей', 'Виктор', 'Галина', 'Елена', 'Иван', 'Катя', 'Сергей'].

in_law('Дима', 'Анна').
% false: Дима — сам муж Анны.
```

Разные цепочки родства могут давать повторные ответы.
`setof/3` собирает все ответы без повторов.

## Блок 4, №4 — первый элемент списка

Задание: определить первый элемент списка.

В записи `[First | Rest]` First — первый элемент, Rest — оставшийся список.
Для этой задачи достаточно сопоставления с головой списка, рекурсия не нужна.

```prolog
first_element([10, 20, 30], First).
% First = 10.

first_element(['Дима', 'Анна'], First).
% First = 'Дима'.

first_element([], First).
% false: у пустого списка нет первого элемента.
```

## Блок 6, №4 — деление первого элемента на остальные

Задание: поделить первый элемент на все остальные элементы числового списка.
Деление выполняется последовательно: для [32, 2, 2, 2]
получаем ((32 / 2) / 2) / 2 = 4.

`divide_first/2` выделяет первый элемент.
`divide_rest/3` делит текущий результат на очередной элемент и рекурсивно
обрабатывает хвост. При пустом хвосте возвращает накопленный результат.
Вводи непустой список чисел. Нулевой делитель даёт `false`.

```prolog
divide_first([32, 2, 2, 2], Result).
% Result = 4.

divide_first([120, 2, 3, 4], Result).
% Result = 5.

divide_first([7], Result).
% Result = 7.

divide_first([0, 2, 3], Result).
% Result = 0.

divide_first([10, 0, 2], Result).
% false.

divide_first([], Result).
% false.
```
