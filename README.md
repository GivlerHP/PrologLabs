# Лабораторные работы по Prolog

Все люди, оценки и расписание вымышлены. Дима обозначен атомом `'Дима'`.

Методичка рассчитана на Visual Prolog 5.2, первая работа и часть 1 второй работы написаны для **SWI-Prolog**: без разделов `domains`, `predicates`, `clauses`, `goal`. Структуры представлены составными термами. Основной файл части 2 второй работы (`Lab2/part2_session.pl`) использует Visual Prolog 5.2 с объявлением альтернативного домена. Для SWISH оставлен `Lab2/part2_session_swi.pl`. Для сдачи нужен онлайн-компилятор, поддерживающий SWI-Prolog. Если преподаватель требует именно Visual Prolog, потребуется другая версия исходников.

## Запуск

Файлы `family.pl`, `part1_tabel.pl` и `part2_session_swi.pl` — самостоятельные программы для SWI-Prolog. `part2_session.pl` требует Visual Prolog 5.2; инструкция — `Lab2/README_visual.md`. Для сдачи загружай по одному файлу и выполняй относящиеся к нему запросы.

В SWI-Prolog открой файл через File → Consult, для первой работы введи `demo.`. Для второй работы используй отдельные запросы из `Lab2/README.md`. В интерактивном окне приглашение `?-` уже показано, вводить его повторно не нужно. Для следующего ответа нажми `;`, для завершения перебора — Enter.

В онлайн-среде с отдельным полем запроса вставь код в редактор, а запрос — в поле запроса (`demo.` для первой работы; для второй — примеры в `Lab2/README.md`). Для первой работы в среде, которая запускает только программу целиком, добавь в конец файла:

```prolog
:- initialization(main).
main :- demo, halt.
```

Для командной строки:

```powershell
swipl -q -s Lab1/family.pl -g demo -t halt
swipl -q -s Lab2/part1_tabel.pl -g "listing(tabel)" -t halt
swipl -q -s Lab2/part2_session_swi.pl -g "listing(session)" -t halt
```

В `.pl` есть русские комментарии. В первой работе доступен `demo/0`, во второй демонстрация выполняется отдельными запросами. Часть 3 лабораторной 2 не включена: вариант для неё не был задан.
